---
description: 启动当前仓库的 AOCI 只读状态面板并返回链接
---

启动 AOCI 面板并把链接交给用户。

1. 运行 `aoci ui --detach --json`。不要用前台 `--open`，不要让命令阻塞会话。
2. 从 JSON 输出里取面板链接，直接给用户可点击的地址。
3. 如果提示已有旧版本面板，按提示先 `aoci ui --stop` 再重试一次；
   如果是本版本已启动的面板，直接复用链接。
4. 说明面板是只读的：只监听回环地址，不改仓库文件，也不影响正在运行的 `aoci mcp`。
5. 如果当前目录不在已初始化仓库内，停止并说明原因。

用户附加参数（可为空，例如其他仓库路径）：{{args}}
